# HR Analytics Dashboard

## Overview

Interactive HR Dashboard built using Microsoft Excel to analyze employee attrition and workforce demographics.

## Features

✔ Employee KPIs
✔ Attrition Analysis
✔ Department Analysis
✔ Education Analysis
✔ Gender Distribution
✔ Age Group Analysis
✔ Job Satisfaction
✔ Interactive Slicers

## Tools Used

- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Conditional Formatting
- Slicers

## Business Insights

• Attrition Rate: 16%
• Highest attrition in Sales Department
• Majority attrition from Bachelor's degree employees
• Employees aged 25–34 contribute the highest attrition
